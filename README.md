# student-management-system-dbms

# Entity-Relationship Database Design for a Student Management System

## KEEYA TRACY

## Description
This project is a Student Management System Database designed using MySQL. The database manages students, lecturers, courses, enrollments, and assignments.

## Tables Created
- Student
- Lecturer
- Course
- Enrollment
- Assignment

## Features Implemented
- Primary Keys
- Foreign Keys
- SQL Queries
- INNER JOIN
- Aggregate Functions
- VIEW

## Tools Used
- MySQL

## How to Run the Project
1. Open MySQL
2. Create a database named student_management_system
3. Import the SQL file
4. Execute the queries
